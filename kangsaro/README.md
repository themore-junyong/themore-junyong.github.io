# 강사로 (시범판)

강사와 강의 업체를 잇는 앱의 첫 체험판입니다. 한 파일(`index.html`)이고, 데이터는 이 기기 브라우저에만 저장됩니다(서버 없음).
맨 위 "체험 중"에서 강사/회사를 바꿔 가며 양쪽 화면을 써 볼 수 있습니다. 예시 데이터는 모두 가짜입니다.

- 강사: 강의 달력(지원→확정→강의 끝→지급), 순수익(강사료−3.3%−교통비), 겹침·주말·공휴일 경고, 공고 붙여넣기 → Gmail 작성 화면(보내기는 직접), 앱 안 공고 원클릭 지원·거르기, 공지·서류, 월별·연말 결산, 프로필 한 번 쓰기
- 회사: 강의 등록(달력에서 날짜 고르기·요일 자동·필수 칸), 지원자 확정, 마감 시 미선정 숨김, 받을 서류·빠진 것, 공지와 읽음 확인, 일정 변경 자동 공지, 대량이체 CSV, 지급 완료 → 강사 입금 확인 알림, 원천세 결산

다음 단계: Firebase 연결(로그인, 역할별 보안 규칙), 개인정보 처리방침.
공고 읽기 코드는 `lecture-app/index.html`에서 가져왔습니다.
