# 강의 진행 앱 (lecture-app)

주소: https://themore-junyong.github.io/lecture-app/ (검색 노출 안 함, noindex)

- 공고 붙여넣기 → 지원 메일 제목·본문 초안 (보낸 메일 18통의 뼈대: 기본형·상세형·양식형·재공지)
- 강의 상태 지원 → 선정 → 준비 → 완료 (+미선정), 단계마다 쓸 안내문 템플릿 추천
- 경고: 첨부 누락, 일정 겹침(앱에 저장한 강의 + 불러온 캘린더 .ics), 공고 요일 오류·주말·공휴일
- 영업 첫 메일 + 3일(평일) 뒤 전화 기록

데이터는 그 기기의 브라우저(localStorage)에만 저장한다. 서버·AI로 아무것도 보내지 않는다.
메일은 자동으로 보내지 않는다(Gmail 작성 창 열기·복사까지). 학생 이름은 앱에 적지 않는다.
공휴일 표는 2026·2027년치만 들어 있다(그 뒤는 주말만 경고).
