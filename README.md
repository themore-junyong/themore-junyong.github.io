# THE MORE 김준용 홈페이지
- `index.html` 한 장짜리 사이트. `posts.json`을 읽어 최근 글을 보여줌.
- `.github/workflows/update.yml` 이 하루 두 번 티스토리·네이버·유튜브 새 글을 모아 `posts.json` 갱신.
- 분류 규칙은 `scripts/build_feed.py` 의 TISTORY_MAP.
- `free/` 댓글 키워드 자료실. 자료 추가는 `free/resources.json` 의 items 맨 위에 한 줄. DM에는 `themore-junyong.github.io/free/#키워드` 링크를 보내면 그 자료가 바로 보임.
